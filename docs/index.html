FlyRank ML Internship · Week 8 Capstone

FlyRank Search Content Opportunity Scoring

Can observed search-performance signals be used to rank pages by content-review opportunity?

Abstract

This capstone asks whether observed search-performance signals can be used to rank pages by content-review opportunity. Using an anonymized FlyRank starter dataset, the analysis constructs a transparent prototype opportunity label based on recent impression decline and evaluates a Logistic Regression model against a majority-class baseline. On the held-out test set, the Logistic Regression model achieved 0.453 precision, 0.663 recall, 0.538 F1, 0.671 ROC-AUC, and 0.467 PR-AUC, while the majority baseline identified no opportunities. The model was then used to generate a ranked review queue with opportunity scores and human-readable reason codes. These results are prototype decision-support evidence and do not establish causal effects, reveal Google's ranking algorithm, or guarantee that changing a recommended page will improve performance.

Introduction / Problem Statement

Content teams need a repeatable way to decide which pages should be reviewed first when search performance changes. Reviewing every page equally is inefficient, while relying on a single metric can miss pages that show multiple signals of potential opportunity.

This project asks whether observed search-performance signals can be combined into a transparent ranking of pages by content-review opportunity. The intended decision is to help a content team prioritize pages for review, monitoring, or further investigation.

The output is a ranked review queue with an opportunity score, supporting reason codes, and an action category. This is decision-support evidence rather than a claim about Google's ranking algorithm or a guarantee that editing a page will improve its future performance.

Decision Supported

Which pages should a content team review first?

The system produces a ranked list that can help prioritize pages for content review, monitoring, or further investigation.

Cost of a wrong call: False positives can waste review time, while false negatives can cause potentially declining pages to be missed.

Dataset

The capstone uses the public FlyRank starter dataset content_refresh_anonymized.csv. The dataset contains anonymized content identifiers and observed search-performance, content, freshness, engagement, and trend fields.

Time Windows

The dataset provides 90-day aggregate performance fields, last-30-day performance fields, and previous-30-day performance fields. The starter CSV does not expose a specific calendar release date in the inspected fields, so this analysis does not claim a specific calendar-period release.

Public-Safe Handling

The analysis uses anonymized content IDs and aggregate fields. Client identifiers are not used as predictive features, and the public analysis does not expose client names, domains, private queries, credentials, or raw private exports.

Methodology

Opportunity Definition

A prototype review_opportunity label was constructed from the recent change in impressions. Among pages with prior-period impressions, the median decline among declining pages was used as the threshold.

-36.84% Decline threshold
9,858 Opportunity pages
32.84% Opportunity rate

Features

The model uses observed content, search, freshness, engagement, and performance-related signals including search volume, competition, word count, content age, days since update, CTR, average position, engagement rate, scroll rate, AI traffic percentage, content type, intent, age tier, freshness tier, word-count tier, character-count tier, impression tier, and position tier.

Leakage Checks

Fields that directly constructed the opportunity label were excluded from the model, including impressions_last_30d, impressions_prev_30d, and recent_impression_change_pct. The closely related trend_direction and trend_pct fields were also excluded.

Validation

The data was split using an 80/20 stratified train/test split, producing 24,000 training rows and 6,000 test rows. The training and test opportunity rates were approximately 32.9%.

The model was compared with a majority-class baseline. Numeric features used median imputation and standardization, while categorical features used most-frequent imputation and one-hot encoding. The main model was Logistic Regression with class balancing.

Results

Majority baseline 0.671 0.000 0.000 0.000 N/A N/A
Logistic Regression 0.626 0.453 0.663 0.538 0.671 0.467

On the held-out test set, Logistic Regression identified a substantial share of the defined opportunity class, with recall of 0.663 and precision of 0.453. Its ROC-AUC was 0.671 and PR-AUC was 0.467.

The majority baseline achieved higher accuracy because it always selected the majority class, but it identified no opportunity pages. Accuracy therefore does not provide a sufficient summary of this imbalanced decision problem.

Feature Interpretation

The strongest positive coefficients included content type, selected word-count tiers, lower/moderate impression tiers, selected position tiers, scroll rate, and days since last update. Strong negative coefficients included the top-three position tier, excellent impression tier, and selected content and age categories.

These coefficients describe associations in the fitted model. They should not be interpreted as causal effects.

Ranked Recommendations

The fitted model produces an opportunity score for each page. The resulting queue is accompanied by human-readable reason codes and action categories.

Rank Action Purpose
1–50 Priority review Initial review queue
51–200 Review queue Secondary review after the first group
201–1,000 Monitor Gather additional evidence
1,001+ Lower priority Remain lower in the review queue unless other evidence changes priority

Example reason codes include recent impression decline, lower CTR, lower impression volume, weaker average position, lack of recent updates, and established content.

These rankings are prioritization aids, not automatic content-editing instructions. A human reviewer should consider page context, search intent, content quality, business importance, and other evidence before taking action.

Limitations and Honest Framing

This analysis uses the anonymized starter dataset because the full FlyRank Warehouse Dataset was not yet available during development. The results should therefore be treated as prototype evidence rather than final warehouse findings.

The review_opportunity label is a constructed analytical definition based on recent impression decline. It is not a directly observed business outcome and should not be interpreted as proof that a page requires a content refresh.

The Logistic Regression model identifies associations within the available data. The coefficients do not establish that the corresponding signals cause search-performance changes.

The model does not reveal or predict Google's ranking algorithm. It also cannot guarantee that editing a recommended page will improve its search performance.

Finally, the ranking should be used as decision support. A human reviewer should consider the page context, search intent, content quality, business importance, and other evidence before taking action.

Temporal Limitation

The prototype opportunity label is based on the recent 30-day change in impressions, while several available features are aggregated over 90 days. These windows therefore overlap. Direct target fields were excluded from the model, but the remaining 90-day aggregates can still contain information from the target period. For this reason, the model should be interpreted as a cross-sectional ranking prototype rather than a clean future-decline forecasting model.
